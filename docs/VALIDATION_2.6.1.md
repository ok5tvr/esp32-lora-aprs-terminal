# Validation checklist - firmware 2.6.1

Version 2.6.1 changes only the order and labels of the main-menu entries.

## Czech menu

Verify this exact order:

1. LoRa APRS
2. Prijate stanice
3. Zpravy
4. Meteostanice
5. Mapa
6. Tracker
7. Stopar
8. DIGI / iGate
9. GPS prijimac
10. Diagnostika
11. Napajeni
12. Nastaveni

## English menu

Verify this exact order:

1. LoRa APRS
2. Received stations
3. Messages
4. Weather stations
5. Map
6. Tracker
7. Trail logger
8. DIGI / iGate
9. GPS receiver
10. Diagnostics
11. Power
12. Settings

## Navigation

- Open every item and verify that it opens the expected screen.
- Verify cyclic navigation from Settings back to LoRa APRS.
- Verify that the map screen header is Mapa in Czech and Map in English.
- Verify that changing language does not change the selected menu index.
